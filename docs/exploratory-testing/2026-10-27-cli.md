# CLI exploratory testing, 2026-10-27

## Setup

Tested commit `18c0094028abf9f119740584e3af55ba30b0a340` in an isolated worktree on Linux amd64. The host had no GHC. The pass used the `haskell:9.4.3` container image and built with `make build`. The application requires only GHC's bundled packages for this build. The repository has no lockfile, so there was no locked dependency install to run. No Cabal dependencies were installed.

The container used a bind mount of the worktree, a worktree-local HOME, and worktree-local test data. The build and `make test` passed. [Terminal output](2026-10-27-cli-output.txt) records the commands' results. The image and container were registered for cleanup before use.

## Journeys

1. **Measure a command and keep its effects.** A command appended `x` three times and returned an average. A shell pipeline appended two lines containing `b` and returned an average. The files contained the expected data after each command.
2. **Correct an invalid invocation.** Missing arguments, `nope`, zero, and negative two each failed with a diagnostic. Repeating with `2` succeeded and printed an average. These checks ran against the same built binary.
3. **Handle a failed command and retry.** A command appended `x` and exited 7. Two fresh replays each exited 1, reported exit code 7, and left one byte, confirming no further iterations. A later successful command returned an average.

## Confirmed bug

[Issue #3](https://github.com/jonbaldie/avg/issues/3) tracks an oversized iteration count that silently wraps. On the tested 64-bit build, `18446744073709551617` ran the command once, printed an average, and exited 0. Two replays began with a missing output file and each left exactly one byte. The program should instead run the requested count or reject it before executing the command. A successful but incorrect measurement can mislead users and omit expected command effects.

CI uses GHC 9.4.8, while this pass used 9.4.3 as named by the README and Dockerfile. An existing [PR #2](https://github.com/jonbaldie/avg/pull/2) notes that mismatch.
